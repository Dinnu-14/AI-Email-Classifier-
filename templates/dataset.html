Dataset Design
  • Balanced Classes: Each category contains an equal number of high-quality sample emails to prevent class imbalance bias.
  • No External Scraping: 100% locally stored in dataset/emails.csv. The app never makes external network calls.
  • Realistic Vocabulary: Contains domain-specific keywords and n-grams for work deadlines, friendly banter, marketing promos, phishing phrases, and security alerts.
  • Split Ratio: 80% ({{ metrics.train_samples }} emails) used for model training; 20% ({{ metrics.test_samples }} emails) strictly reserved for testing.
